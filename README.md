# exam-screen-capture（Windows版）

プログラミング試験中の画面を定期的に保存し、終了時に提出用ZIPを作成するツールです。  
このREADMEは **Windows版のみ** を対象にしています（`for_mac` 配下は対象外）。

## 構成ファイル（Windows）

- `1_start.bat`  
  試験開始時の起動バッチ
- `start.ps1`  
  オフライン確認、学籍番号受付、保存先準備、監視プロセス起動（監視起動を最優先で実行し、以降の付随処理は失敗しても試験進行を止めない構成）
- `capture.ps1`  
  画面キャプチャ、画面上部ステータス表示、試験中ネットワーク監視、ロック画面制御
- `2_submit.bat`  
  試験終了時の提出バッチ
- `submit.ps1`  
  監視プロセス停止、ZIP作成、提出フォルダへの配置、後処理

## 機能一覧（Windows）

1. **試験開始前のオフライン確認**  
   `1_start.bat` 実行時に、外部サーバーへの通信は一切行わず、Windowsのネットワーク状態情報（`GetIsNetworkAvailable` / `Get-NetConnectionProfile` / デフォルトゲートウェイへのPing）のみでオンライン判定を行い、オンライン時は開始をブロックします。
2. **学籍番号入力と作業フォルダ作成**  
   新規開始時に学籍番号（8桁）を受け付け、内部保存先（`%LOCALAPPDATA%`配下）を準備します。
3. **未提出データの自動再開**  
   内部保存先に前回データがある場合は自動的に再開します（OneDriveと無関係のため常に高速）。
4. **誤提出後の復元再開**  
   解答フォルダ候補内の提出ZIPを検知できる場合、内部保存先へ復元して再開します。探索・復元処理はいずれもタイムアウト保護されており、OneDrive同期の遅延・ハングが発生しても一定時間で打ち切られ、監視プロセスの起動を妨げません。
5. **画面キャプチャ（全画面・マルチモニタ対応）**  
   画面全体をJPEGで連番保存し、監視記録を継続します。
6. **監視バー表示**  
   画面上部に学籍番号・撮影枚数・時刻を表示する半透明・クリックスルーの常時最前面バーを表示します（マウスを乗せるとさらに透明化）。
7. **試験中ネットワーク監視とロック画面表示**  
   試験中も0.5秒間隔でチェック機会を持ち、1〜10秒間隔で実際の接続判定を行います。オンライン検知時はロック画面（紺系配色）を表示して警告ログを記録します。
8. **TA専用解除**  
   ロック解除にはUSBルートの `TA_unlock.key` と `ta_unlock.pfx`、および正しいPINが必要です。
9. **提出ZIP作成と後処理**  
   `2_submit.bat` 実行で監視プロセス停止、ZIP化、提出フォルダ配置、内部保存領域削除を行います。解答フォルダの探索・ZIP移動もタイムアウト保護されており、失敗時はZIPを一時フォルダに残したまま明示的に警告します。
10. **進捗表示**  
    起動・提出のいずれも、時間のかかりうる処理（誤提出データ確認・回答フォルダ準備・ZIP移動など）の前に、最大待機時間を含む進捗メッセージを表示します。

## 受験者向け使い方

### 1. 試験開始

1. `1_start.bat` を実行します。
2. インターネット接続が検出された場合は、オフラインにして再確認します。
3. 学籍番号（半角数字8桁）を入力します（未提出データや誤提出ZIPが見つかった場合は自動的に引き継がれ、入力は不要です）。
4. 「キャプチャを開始しました．」と表示された時点で監視は起動済みです。画面上部にステータスバー（`[学籍番号] 試験中: ...`）が表示されたら試験を始めてください。
5. その後も回答用フォルダの準備などがバックグラウンド的に続きますが、監視自体はすでに動作しています。

### 2. 試験中

- ツールが1〜60秒間隔で画面全体（マルチモニタ含む）をJPEG保存します。
- ネットワーク接続を検知するとロック画面が表示されます。
- ロック画面が出た場合は、受験者は操作せずTAを呼んでください。

### 3. 試験終了

1. 解答ファイルを解答用フォルダに保存します。
2. `2_submit.bat` を実行します。
3. ZIPファイルが解答用フォルダ（見つからない場合はデスクトップ直下、それも失敗した場合は一時フォルダ）に作成されたことを、画面の表示で確認します。
4. 解答ファイルとZIPを提出します。

## 保存先仕様

- 内部保存先（キャプチャ作業領域、常にローカル固定）  
  `%LOCALAPPDATA%\Microsoft\CaptureSystem\{学籍番号}_{YYYYMMDD}`
- 解答用フォルダ（優先順、いずれもOneDrive同期対象と判定されたパスは自動的に除外）  
  1. シェルAPIが返すデスクトップ  
  2. `%USERPROFILE%\Desktop`（本来のデスクトップ）  
  3. `%USERPROFILE%\Downloads`  
  4. `C:\ExamSystem`（最終フォールバック）
- 提出ZIP名  
  `{学籍番号}_{YYYYMMDD_HHMMSS}.zip`

## 復旧・再開

- 前回の未提出データが内部保存先にあれば、`1_start.bat` 実行時に再開します（ローカル完結・常に高速）。
- 誤って提出した場合でも、解答フォルダ候補内の最新ZIPが見つかれば、監視プロセス起動後に復元して再開します。
- 解答用フォルダの探索・作成・ZIP復元・ZIP移動は、いずれも一定時間（数秒〜数十秒）でタイムアウトするよう保護されています。OneDrive同期の遅延やハングが起きても、監視プロセスの起動や試験進行そのものは止まりません。全候補が失敗した場合は、画面に明示的な警告が表示されます（無言で失敗しません）。

## TA向け補足（ロック解除）

ロック画面の解除には、以下を満たすUSBメモリが必要です。

- USBルートに `TA_unlock.key`
- USBルートに `ta_unlock.pfx`
- 解除時に正しいPIN入力

※証明書のサムプリント一致検証を行うため、正しいTA用メディア以外では解除できません。

ロック画面が表示中（TA解除が完了していない状態）は、`2_submit.bat` による提出処理自体がブロックされます。

## 注意事項

- 本ツールはWindows PowerShell実行を前提にしています。
- 実行ポリシーの都合上、バッチ内で `-ExecutionPolicy Bypass` を利用しています。
- 起動・提出は必ずリポジトリ直下の `1_start.bat` / `2_submit.bat` から行ってください。
- `capture.ps1` / `start.ps1` / `submit.ps1` は日本語文字列を含むため、**UTF-8（BOM付き）で保存する必要があります**。BOMなしで保存するとWindows PowerShell 5.1がShift-JISとして読み込み、構文エラーで起動できなくなります。編集時は保存形式で「UTF-8 (BOM付き)」を明示的に選択してください。
