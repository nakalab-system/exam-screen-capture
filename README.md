# 画面キャプチャツールの使用方法

試験の公正性を保つため、試験中の画面をバックグラウンドで定期的に保存します。
以下の手順に従ってツールを実行し、試験に臨んでください。

## 1. ツールのダウンロードと準備
1. 指定されたURLから、このGitHubページを開きます。
2. 画面右上にある緑色の **「<> Code」** ボタンをクリックし、**「Download ZIP」** を選択してダウンロードします。
3. ダウンロードしたZIPファイルを右クリックし、**「すべて展開」** を選択してフォルダを開きます。
4. 展開されたフォルダの中に、以下の実行ファイルがあることを確認してください。（※システムファイルは誤操作防止のため隠しファイル設定になっています）
   - `1_start.bat`
   - `2_submit.bat`

## 2. 実行手順（試験開始前）
1. 試験開始直前に **`1_start.bat`** をダブルクリックします。
2. *※「WindowsによってPCが保護されました」と表示された場合は、**「詳細情報」** をクリックし、**「実行」** を選択してください。*
3. 黒い画面が立ち上がり、学籍番号の入力を求められます。**半角数字8桁** で正しく入力し、Enterキーを押してください。
4. 「画面キャプチャを開始しました...」と表示された後、黒い画面が自動で閉じます。

### 💡 動作確認と監視バーについて
正常に起動すると、画面上部の中央に **`[学籍番号] 監視中: 〇枚 (HH:mm)`** という緑色のステータスバーが常に表示されます。
* **邪魔になりません:** バーの上にマウスカーソルを乗せると、**自動的にほぼ透明になり、そのまま後ろにあるブラウザのタブやWordのボタンなどをクリックできます**。
* 試験中はこのバーが表示された状態のまま進めてください。

## 3. 試験終了後の提出方法
1. 試験が終了したら、**`2_submit.bat`** をダブルクリックしてキャプチャを停止します。
2. 自動的にデータが圧縮され、**デスクトップに `学籍番号_日時.zip` というファイルが作成されます**。
   * *※OneDrive等の影響でデスクトップに作成できない場合は、自動的に「ダウンロード」フォルダに作成されます。画面のメッセージをよく確認してください。*
3. 「処理完了」のメッセージが出たら、キーを押して黒い画面を閉じます。
4. 作成された **ZIPファイル** を、試験監督（TA）の指示に従って提出（USBメモリへの保存など）してください。
5. 提出用ファイルが作成されると、PC内に残った一時保存データは安全に自動削除されます。

## 4. トラブル時の連絡
以下の場合は、PCに触らず **すぐに試験監督（TA）へ挙手して報告** してください。
* `1_start.bat` を実行しても、画面上部に監視バー（緑色の文字）が表示されない場合。
* 監視バーが消えてしまった場合。
* `2_submit.bat` を実行した際、赤字でエラーが出たり、ZIPファイルが見つからない場合。
