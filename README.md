# 画面キャプチャツール使用マニュアル

このツールは、試験中の画面を定期的に自動保存し、試験終了後に提出用ZIPを作成するシステムです。  
**最新版では、オフライン確認・自動再開・誤終了からの復元・ネット接続検知時ロック画面** などの機能が追加されています。

---

## できること（実装済み機能一覧）

### 1) 試験開始前のオフライン強制確認
- `1_start.bat` 実行時に、`8.8.8.8` への Ping でネット接続を確認します。
- 接続中の場合は警告を表示し、**オフラインになるまで先に進めません**。

### 2) 学籍番号入力と保存先の自動準備
- 学籍番号（**半角数字8桁**）を入力して開始します（新規開始時）。
- 内部保存先（隠し領域）として以下を使用します。  
  - `%LOCALAPPDATA%\Microsoft\CaptureSystem\{学籍番号}_{日付}`
- 同時に提出用の解答フォルダを作成します。  
  - 第1候補: `デスクトップ\{学籍番号}_{日付}`  
  - 代替: `ダウンロード\{学籍番号}_{日付}`（デスクトップ作成不可時）

### 3) 強制終了後の自動再開
- 内部保存先に未提出データ（隠しフォルダ）が残っている場合、**自動検知して再開**します。

### 4) 誤って提出した場合の自動復元
- すでに作成済みの提出ZIP（`{学籍番号}_*.zip`）を検知した場合、  
  ZIPから画像データを内部保存先へ復元し、**続きから再開**します。
- 復元後、使用したZIPは削除されます（重複防止）。

### 5) 監視バー表示（画面上部中央）
- 起動中は上部中央にステータスバーを常時表示します。  
  例: `[学籍番号] 試験中: 12枚 (14:23)`
- バーは最前面表示ですが、**マウスが重なるとほぼ透明化**し、操作の邪魔を減らします。

### 6) 全画面・マルチモニタ対応キャプチャ
- 全モニタ範囲を結合して撮影します（負座標モニタ配置にも対応）。
- JPEGで連番保存します。  
  - 形式: `{学籍番号}_{連番2桁}_{時刻HHmmss}.jpg`
- 撮影間隔は **0～59秒のランダム**（毎回再設定）です。

### 7) 試験中ネット接続の監視と警告ロック
- 試験中は5秒ごとにネット接続（Ping）を監視します。
- 接続を検知すると `network_warning.log` に記録し、**警告ロック画面**を表示します。
- ロック画面は通常操作で閉じられず、**TA用USBキー**（`nklab_unlock.key`）を含むリムーバブルメディアを挿入すると解除されます。

### 8) プロセス名の偽装実行
- キャプチャ本体は `WinSysMonitor.exe` 名で起動します（PowerShell実体をコピーして利用）。
- 提出時はこの偽装プロセスを終了してから圧縮処理に進みます。

### 9) 提出時の自動圧縮・配置
- `2_submit.bat` 実行でキャプチャを停止し、内部保存データをZIP化します。
- ZIP保存先:
  - `デスクトップ\{学籍番号}_{日付}` が存在すればそこ
  - なければ `ダウンロード\{学籍番号}_{日付}`
  - どちらも無ければデスクトップ直下
- ZIP名: `{学籍番号}_{yyyyMMdd_HHmmss}.zip`
- 完了後、内部保存フォルダ（`%LOCALAPPDATA%\Microsoft\CaptureSystem`）は削除されます。

## ファイル構成

- `1_start.bat`  
  起動用バッチ。`start.ps1` を実行。
- `start.ps1`  
  事前オフライン確認、再開/復元判定、保存先準備、キャプチャプロセス起動。
- `capture.ps1`  
  画面撮影、監視バー表示、ネット監視、ロック画面制御。
- `2_submit.bat`  
  提出用バッチ。`submit.ps1` を実行。
- `submit.ps1`  
  偽装プロセス停止、画像ZIP作成、提出フォルダ配置、後始末。
- `README.md`  
  この説明書。

## 利用手順（受験者向け）

### 1. 事前準備
1. このリポジトリをダウンロード（Code → Download ZIP）して展開。
2. 展開先に `1_start.bat` と `2_submit.bat` があることを確認。

### 2. 試験開始時
1. `1_start.bat` を実行。
2. Windows警告が出た場合は「詳細情報」→「実行」。
3. 画面指示に従い、ネットワークをオフライン化。
4. 学籍番号（8桁）を入力。
5. 解答用フォルダ作成メッセージを確認。
6. キャプチャ開始後、ウィンドウは自動で閉じます。  
   以後、上部の監視バーが表示されていれば正常動作中です。

### 3. 試験終了時
1. 解答ファイル（例: `.cpp`）を解答用フォルダに保存済みであることを確認。
2. `2_submit.bat` を実行。
3. 作成されたZIPが解答用フォルダ内にあることを確認。
4. **解答ファイル + ZIP を含むフォルダごと**提出。

## 運用上の注意

- **試験中はPCをオフラインで維持**してください。
- 監視バーが消えた・エラー表示が出た場合は、すぐに監督者へ連絡してください。
- ロック画面表示時は受験者が解除せず、監督者の指示に従ってください。
- 本ツールは Windows + PowerShell を前提としています。

## トラブル時

### Q1. 間違えて `2_submit.bat` を押してしまった
- 再度 `1_start.bat` を実行してください。  
  提出ZIPが見つかれば自動復元して再開します。

### Q2. PC再起動・強制終了が発生した
- 再度 `1_start.bat` を実行してください。  
  未提出データがあれば自動再開します。

### Q3. ZIPが見つからない
- まず `デスクトップ\{学籍番号}_{日付}` を確認。  
- 次に `ダウンロード\{学籍番号}_{日付}` を確認。  
- 最終的にデスクトップ直下も確認してください。

---

## 監督者（TA）向け補足

- ネット接続検知時のロック解除には、リムーバブルメディア直下に  
  `nklab_unlock.key` を置いたUSBメモリを使用します。
- 当該ファイル名が一致しないと解除されません（大文字小文字はWindows通常設定では不問）。
