# 画面キャプチャツールの使用方法

試験の公正性を保つため、試験中の画面をバックグラウンドで定期的に保存します。
以下の手順に従ってツールを実行し、試験に臨んでください。

## 1. ツールのダウンロードと準備
1. 指定されたURLから、このGitHubページを開きます。
2. 画面右上にある緑色の **「<> Code」** ボタンをクリックし、**「Download ZIP」** を選択してダウンロードします。
3. ダウンロードしたZIPファイルを右クリックし、**「すべて展開」** を選択してフォルダを開きます。
4. 展開されたフォルダの中に、以下の実行ファイルがあることを確認してください。（※システムファイルは誤操作防止のため隠しファイル設定になっています）
   - `1_start.bat`
   - `2_submit.bat`

## 2. 実行手順（試験開始前）
1. 試験開始直前に **「1_start.bat」** をダブルクリックします。
2. *※「WindowsによってPCが保護されました」と表示された場合は、**「詳細情報」** をクリックし、**「実行」** を選択してください。*
3. 黒い画面が立ち上がり、学籍番号の入力を求められます。**半角数字8桁** で正しく入力し、Enterキーを押してください。
4. **【重要】入力が完了すると、デスクトップに「(学籍番号)_(日付)」という解答用フォルダが自動作成されます。**
   試験中に作成したプログラム（.cppファイルなど）は、必ずこのフォルダの中に保存してください。
   * *※OneDrive等の影響でデスクトップに作成できない場合は、自動的に「ダウンロード」フォルダに作成されます。画面の案内をよく確認してください。*
5. 「キャプチャを開始しました...」と表示された後、黒い画面が自動で閉じます。試験を開始してください。

### 💡 動作確認と監視バーについて
正常に起動すると、画面上部の中央に **`[学籍番号] 試験中: 〇枚 (HH:mm)`** という黄色のステータスバーが常に表示されます。
* **邪魔になりません:** バーの上にマウスカーソルを乗せると、**自動的にほぼ透明になり、そのまま後ろにあるブラウザのタブやWordのボタンなどをクリックできます**。
* 試験中はこのバーが表示された状態のまま進めてください。

## 3. 試験終了後の提出方法
1. 試験が終了し、cppファイルを保存したら、**「2_submit.bat」** をダブルクリックしてキャプチャを停止します。
2. 自動的にバックグラウンドのキャプチャ画像が圧縮され、**解答用フォルダの中に `(学籍番号)_(日時).zip` が自動で格納されます**。
3. 「処理完了」のメッセージが出たら、いずれかのキーを押して黒い画面を閉じます。
4. 解答プログラムと画像ZIPが入った **「(学籍番号)_(日付) のフォルダごと」** を、試験監督（TA）の指示に従って提出（USBメモリへのコピー等）してください。

## 4. トラブル時の連絡・対応
* **間違えて途中で「2_submit.bat」を押してしまった場合**
  焦らずに、もう一度 **「1_start.bat」** をダブルクリックしてください。自動的に提出ファイルからデータを復元し、そのまま続きからキャプチャを再開できます（学籍番号の再入力は不要です）。
* **PCがフリーズして強制再起動した場合**
  再起動後、もう一度 **「1_start.bat」** を実行してください。消えずに残っていたデータから自動で続きが再開されます。
* **その他、エラーが出る場合**
  赤字のエラーが出たり、キャプチャバーが消えて直らない場合は、PCに触らず **すぐに試験監督（TA）へ挙手して報告** してください。
