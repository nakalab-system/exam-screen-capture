## 6. PDF 修正時に書くべき事項

- [ ] `start.sh` で開始すること
- [ ] `finish.sh` で終了 / 提出すること
- [ ] 画面収録権限の付与方法
- [ ] 開始前はオフライン必須であること
- [ ] 学籍番号入力が必要なこと
- [ ] 証拠画像はバックグラウンドで自動撮影されること
- [ ] 提出 ZIP の保存先
- [ ] 画像名 / ZIP名の命名ルール
- [ ] 試験中は Wi-Fi を ON にしないこと
- [ ] ネット接続検知で警告状態になること
- [ ] 警告状態では提出できないこと
- [ ] TA用USB + TA PIN で解除する運用であること
- [ ] 解除前に Wi-Fi を OFF にする必要があること
- [ ] `swift` 利用可端末ではバー / リッチロック画面が使われること
- [ ] `swift` 利用不可端末では簡易ロック画面へフォールバックすること
- [ ] `swift` 利用不可端末ではバーは出ないが試験運用は継続可能であること
- [ ] 再開機能 / 復元再開機能があること
- [ ] ネット検知後に解除できない場合の確認事項
