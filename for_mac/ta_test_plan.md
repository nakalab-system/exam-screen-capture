# mac版 TA確認用テストプラン

この文書は、現状の mac版
`for_mac/配布用formac/CaptureSystem`
を TA メンバーに確認してもらうためのテスト計画です。

目的は次の 3 点です。

- 実運用に必要な基本機能が、別の mac 端末でも動くか確認する
- `swift` 利用可否による挙動差を確認する
- 試験中ネットワーク検知と TA 解除の運用手順を事前に固める

---

## 1. 事前共有事項

- 現在の mac版は、**単一モニタ前提**での運用を基本とする
- **マルチモニタ全体キャプチャは未対応**
- **USB / 証明書ベースの TA解除は未対応**
- TA解除は、現時点では **TAパスワード方式**
- `swift` が使える端末では
  - 常時最前面バーあり
  - リッチなロック画面あり
- `swift` が使えない端末では
  - 常時バーなし
  - 簡易ダイアログ型ロック画面へ自動フォールバック
  - ただし最低限の監督機能は継続

---

## 2. テスト対象機能

- 学籍番号入力
- 保存フォルダ名 / 画像名 / ZIP名
- 画面収録権限チェック
- 開始前オフライン確認
- キャプチャ継続
- 常時最前面バー
- 試験中ネットワーク監視
- 警告ログ出力
- ロック画面
- TA解除
- 解除時 Wi-Fi オフ確認
- 提出拒否
- ZIP 作成
- 未提出データ再開
- 提出済み ZIP からの復元再開
- `swift` 非対応時フォールバック

---

## 3. 事前確認

### 3-1. 端末情報の記録

各確認端末について、最低限次を記録する。

- macOS バージョン
- 機種
- Apple Silicon / Intel
- 使用ターミナル
  例: `Terminal.app`, `iTerm`

### 3-2. `swift` の確認

ターミナルで次を実行する。

```sh
swift --version
```

確認結果は次のどちらかで記録する。

- `swift` 利用可
- `swift` 利用不可

### 3-3. 権限確認

対象ターミナルアプリに対して、画面収録権限が付与できるか確認する。

---

## 4. テストケース

## TC-01 基本起動

### 手順

1. `start.sh` を実行する
2. 学籍番号を入力する
3. 画面収録権限案内が出ることを確認する
4. 撮影開始の案内が出ることを確認する

### 期待結果

- 二重起動でなければ開始できる
- 学籍番号が保存される
- エラーなく開始する

---

## TC-02 保存フォルダ・画像名・ZIP名

### 手順

1. 数枚撮影されるまで待つ
2. `finish.sh` を実行する
3. 作成物を確認する

### 期待結果

- 保存フォルダ:
  `{学籍番号}_{YYYYMMDD}`
- 画像名:
  `{学籍番号}_{連番3桁}_{HHmmss}.jpg`
- ZIP名:
  `{学籍番号}_{YYYYMMDD_HHMMSS}.zip`
- ZIP は解答用フォルダに出力される

---

## TC-03 開始前オフライン確認

### 手順

1. Wi-Fi を ON にした状態で `start.sh` を実行する
2. 警告が出ることを確認する
3. Wi-Fi を OFF にする
4. 再確認して開始する

### 期待結果

- オンライン中は開始できない
- オフライン化後に開始できる

---

## TC-04 常時最前面バー (`swift` 利用可端末)

### 手順

1. `swift` 利用可端末で `start.sh` を実行する
2. バーの表示を確認する
3. マウスを重ねて透過を確認する
4. バー下のウィンドウが操作できるか確認する

### 期待結果

- 上端中央にバーが出る
- 学籍番号、枚数、時刻が表示される
- hover で薄くなる
- バーがあっても下の UI を操作できる

---

## TC-05 `swift` 非対応時の開始

### 手順

1. `swift` が使えない端末で `start.sh` を実行する
2. 案内ダイアログを確認する
3. 試験開始する

### 期待結果

- `swift` 不可の案内が出る
- 常時バーは出ない
- それ以外の試験機能は開始できる

---

## TC-06 試験中ネットワーク検知

### 手順

1. 試験開始後、しばらく待つ
2. Wi-Fi を ON にする
3. 数秒から十数秒待つ

### 期待結果

- ネット接続が検知される
- `network_warning.log` が作成される
- ロック状態へ移行する
- 提出が拒否される

---

## TC-07 リッチなロック画面 (`swift` 利用可端末)

### 手順

1. `swift` 利用可端末でネット接続を検知させる
2. ロック画面の表示を確認する
3. `背景透過` ボタン長押しを確認する

### 期待結果

- 大きな警告 UI が表示される
- 背景透過ボタン長押しで背後確認できる
- パスワード入力欄に入力できる

---

## TC-08 簡易ロック画面 (`swift` 利用不可端末)

### 手順

1. `swift` 利用不可端末でネット接続を検知させる
2. ロック画面の挙動を確認する

### 期待結果

- 専用 UI ではなく簡易ダイアログで動作する
- それでも解除前の Wi-Fi オフ確認と TAパスワード確認が行われる

---

## TC-09 解除時 Wi-Fi オフ確認

### 手順

1. ネット接続検知後、Wi-Fi を ON のまま `TA解除を実行` する
2. 解除拒否を確認する
3. Wi-Fi を OFF にする
4. 再度解除を実行する

### 期待結果

- Wi-Fi ON 中は解除できない
- Wi-Fi OFF 後のみ解除判定へ進む

---

## TC-10 TAパスワード解除

### 手順

1. 誤ったパスワードを入力する
2. 正しい TAパスワードを入力する

### 期待結果

- 誤パスワードでは解除失敗する
- 正しいパスワードで解除できる
- ロック状態が解除され、提出可能へ戻る

---

## TC-11 ロック中の提出拒否

### 手順

1. ネット接続検知後、未解除のまま `finish.sh` を実行する

### 期待結果

- 提出拒否ダイアログが出る
- ZIP 作成は行われない

---

## TC-12 通常提出

### 手順

1. ロックされていない通常状態で `finish.sh` を実行する

### 期待結果

- ZIP が作成される
- 解答用フォルダに保存される
- 試験用保存フォルダは後処理される

---

## TC-13 未提出データ再開

### 手順

1. 試験開始後、提出せず終了する
2. 再度 `start.sh` を実行する

### 期待結果

- 当日の未提出データが見つかった旨が表示される
- 学籍番号を再入力せず再開できる
- 連番が継続する

---

## TC-14 提出済み ZIP からの復元再開

### 手順

1. いったん通常提出する
2. 再度 `start.sh` を実行する

### 期待結果

- 当日の提出済み ZIP が見つかれば復元再開できる
- ZIP は復元後に再利用されないよう処理される

---

## 5. 記録してほしい不具合

- `swift --version` の成否
- 画面収録権限付与で詰まった点
- バーが出ない / 崩れる
- ロック画面に入力できない
- Wi-Fi OFF 判定の誤動作
- 提出拒否が効かない
- ZIP 作成失敗
- 再開 / 復元再開失敗
- Intel / Apple Silicon での差

## 7. 使い方PDF 修正時に書くべき事項

### 必須

- 起動方法
  `start.sh` を使うこと
- 終了 / 提出方法
  `finish.sh` を使うこと
- 画面収録権限の付与方法
- 開始前はオフライン必須であること
- 学籍番号入力が必要なこと
- 証拠画像はバックグラウンドで自動撮影されること
- 提出 ZIP の保存先
  デスクトップ優先、失敗時ダウンロード
- 画像名 / ZIP名の命名ルール

### 試験中の注意

- 試験中は Wi-Fi を ON にしないこと
- ネット接続が検出されると警告状態になること
- 警告状態では提出できないこと
- TA の指示があるまで操作しないこと

### TA / 監督向け

- TAパスワードで解除する運用であること
- 解除前に Wi-Fi を OFF にする必要があること
- `swift` 利用可端末ではリッチなロック画面になること
- `swift` 利用不可端末では簡易ダイアログへフォールバックすること
- `swift` 利用可端末では常時バーが出ること
- `swift` 利用不可端末ではバーは出ないが、試験運用自体は継続可能であること

### トラブル時

- 画面収録権限が通らない場合の対処
- `swift` が使えない場合の挙動
- 再開機能があること
- 復元再開機能があること
- ネット検知後に解除できない場合の確認事項
  Wi-Fi が OFF か、TAパスワードが正しいか
